# 경성대·부경대역 3D 안내도

지하철역 내부 구조를 3D로 보면서 출구에서 승강장까지 가는 길을 안내하는 웹 페이지입니다.

## 기능
- 마우스 드래그로 회전, 휠로 확대·축소, 우클릭 드래그로 이동
- 1~6번 출구와 승차 방면(남천역 / 대연역)을 고르면 3D 경로 표시
- 엘리베이터만 이용하는 경로 옵션
- B1 / B2 / B3 층별 보기

## 실행
빌드가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.
(Three.js와 폰트는 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 기술
- Three.js r128 (OrbitControls)
- 순수 HTML / CSS / JavaScript

## 참고
역 구조는 안내도를 바탕으로 단순화한 모형이며, 거리와 소요 시간은 추정값입니다.
